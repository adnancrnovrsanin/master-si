Uvodno predavanje, Uvod u NLP, Mašinsko učenje, Obučavanje i evaluacija modela, Naivni Bajesov klasifikator, Linearna i logistička regresija, SVM, Zadaci u NLP, `Scikit-learn intro.ipynb`, dataset `SerbMR-2C.csv`.
